# Change: 한글 번역 지원 추가

## Why
현재 애플리케이션은 영어(en), 아랍어(ar), 프랑스어(fr)만 지원하고 있어 한국 사용자가 사용하기 불편합니다.
한글 번역을 추가하여 한국 사용자 경험을 개선하고, 한국 시장에서의 접근성을 높이고자 합니다.

## What Changes
- 한글 번역 파일 `ko.json` 추가
- 모든 UI 요소, 메뉴, 페이지 제목을 한글로 번역
- 언어 선택 드롭다운에 한글 옵션 추가
- Vuetify 컴포넌트의 기본 텍스트도 한글화

## Impact
- **영향받는 스펙**: internationalization (새로 생성)
- **영향받는 코드**:
  - `src/plugins/i18n/locales/` - ko.json 추가
  - 언어 선택 드롭다운을 사용하는 모든 페이지
  - 네비게이션 메뉴 구조
- **호환성**: 기존 기능에 영향 없음 (언어 추가만 수행)
- **사용자 경험**: 한국 사용자의 접근성 및 이해도 향상
